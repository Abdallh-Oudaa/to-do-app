# 📋 To-Do App

## 📝 Description

A simple and efficient To-Do app designed to help users manage their daily tasks with ease. Users can add, view, and manage their tasks through a clean and intuitive interface.

---

## 🚀 Features

- 🔐 Login Screen  
- 🧾 Register Screen  
- 🏠 Home Screen  
- ➕ Add Task  
- ⚙️ Settings  
- 📄 Task Details  

---

## 🛠️ Tech Stack

- 💙 Flutter  
- 🔥 Firebase Firestore  
- 🔐 Firebase Authentication  
- 🧠 MVVM Pattern  
- 📦 Provider (State Management)
